# AI Photo Enhancer Bot

Telegram бот для улучшения качества фото и удаления морщин с сохранением лица.

## Функции
- Улучшение качества фото (шум, резкость, контраст)
- Удаление морщин (по запросу, естественный результат)
- Лицо НЕ меняется
- Фото НЕ сохраняются

## Юридическая защита
- 2 шага согласия (обработка + права на фото)
- Отзыв согласия в любой момент `/revoke`
- Логирование всех действий
- Пользователь несёт ответственность за загружаемые фото

## Команды
| Команда | Что делает |
|---------|-----------|
| `/start` | Начать работу (дать согласие) |
| `/revoke` | Отозвать все согласия |

## Запуск на bothost.ru
1. Загрузить `bot.py` и `requirements.txt` в GitHub
2. В панели bothost создать бота → выбрать GitHub репозиторий
3. Добавить переменные: `BOT_TOKEN` и `CHANNEL_ID=@brmodels095`
4. Запустить
